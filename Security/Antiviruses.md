# Antiviruses

An **antivrius** is a software program designed to detect, prevent, and remove malicious software (malware) from computers and other devices. It helps protect against viruses, worms, 
trojans, ransomware, spyware, adware, and other types of malware that can compromise the security and functionality of a system.

--- 

## How Antiviruses Work 

### Signature-Based Detection

**Signature-based detection** is the most common method used by antivirus software. It involves scanning files and comparing them to a database of known malware signatures. 
If a match is found, the antivirus can take action to quarantine or remove the threat.

### Heuristic Analysis

**Heuristic analysis** is a technique used to identify new or unknown malware by analyzing the behavior and characteristics of files. It uses a lot meta data, 
characteristics and patterns of the code, etc.

### Endpoint Detection 

**Endpoint detection** is a method that monitors the behavior of applications and processes on a device to identify suspicious activity. It can detect malware that may 
not have a known signature. Depending on the activities of a program like sending data to a remote server without user consents, modifying system files, etc. an 
antivirus can flag it as malicious.
